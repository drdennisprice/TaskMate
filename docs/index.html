Google Sheets Time Log — Setup Guide

Connect the TaskMate side panel's time tracker to a Google Sheet in about five minutes. No coding required.

1 Create a Google Sheet

Open sheets.new to create a blank spreadsheet. Give it any name, e.g. "TaskMate Time Log".

2 Add the Apps Script

In the spreadsheet, go to Extensions → Apps Script. Delete the placeholder code in Code.gs and paste in the full script below.

Download Code.gs

Then save the project (Ctrl/Cmd + S).

3 Run setup once

In the Apps Script editor, select the function setupAllSheets from the dropdown at the top and click Run. The first run will ask you to authorize access to your own spreadsheet — this is expected, approve it.

This creates three tabs: TimeLog (raw events), Sessions (one row per completed session), and Report (generated summaries).

4 Deploy as a Web App

Click Deploy → New deployment, choose type Web app, then set:

Execute asMe
Who has accessAnyone

Click Deploy, authorize again if prompted, then copy the Web app URL it gives you.

The "Anyone" access setting only allows requests carrying your private deployment URL to write to this sheet — it does not make the sheet itself public. Keep the URL private, same as a password.

5 Paste the URL into TaskMate

Open the TaskMate side panel, click the ⚙ icon in the time tracker bar, paste the Web App URL into Apps Script Web App URL, and click Save.

Reload the spreadsheet tab in your browser — a TaskMate menu will appear next to Help.

Using the reports

From the spreadsheet menu, TaskMate → Reporting gives you This week / Last week / This month / Last month / Custom range summaries, each with:

  • Totals by task (sessions, hours as h:mm and decimal, % of total)
  • A grand total row
  • Session-level detail for audit

TaskMate → Refresh Sessions tab rebuilds the Sessions sheet from TimeLog if it ever gets out of sync.

Totals are calculated from Stop rows only — column E (Elapsed minutes) already excludes paused time.

Set your spreadsheet's time zone

Go to File → Settings → Time zone in the spreadsheet and set it to your local zone, so weekly/monthly report boundaries line up correctly.

Troubleshooting

  • Nothing appears in TimeLog — re-check the Web App URL was pasted in full, including /exec at the end.
  • Authorization required again — Apps Script occasionally asks you to re-authorize after edits to the script; just approve it and redeploy if needed.
  • Want to change the script later — edit Code.gs in the Apps Script editor directly, save, then create a new deployment version (Deploy → Manage deployments → Edit → New version) so the change takes effect.
